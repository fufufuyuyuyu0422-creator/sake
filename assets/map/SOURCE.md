# 地図データの出典

- `japan.json`: 日本の海岸線ポリゴン。各要素は [[経度, 緯度], ...] のリング（主要4島と周辺の大きめの島、計13）
- 元データ: Natural Earth 1:10m（パブリックドメイン）を TopoJSON 化した npm パッケージ `world-atlas@2.0.2` の `countries-10m.json` から、Japan の形状を取り出したもの
- 加工: 小さな島を除外（面積 0.03平方度未満）、座標を 0.01度単位に丸め、近すぎる点を間引き
- 精度: 県単位〜地方単位の表示向け。市区町村レベルまで寄ると海岸線がカクカクする（ズームの目安は `render/frames2.py` の縮尺400程度まで）
- 県境は入っていない。県境が必要になったら別のデータを用意する
