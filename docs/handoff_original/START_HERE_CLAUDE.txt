Claudeへの制作依頼（最初にこのファイルを読んでください）

このZIPは、YouTube新企画「酒の歴史・文化・科学を旅する教養チャンネル」の引き継ぎパックです。
あなた（Claude/Claude Code）には、先行試作の失敗を繰り返さず、実在の参考動画を先に分析したうえで、40〜60秒の『音声入り・完成した』検証用動画を制作してほしいです。

【最初に実行すること】
1. PROJECT_BRIEF.md / PRODUCTION_RULES.md / REFERENCES.md と同梱素材を読む。過去の34秒動画は「失敗例」であって採用すべきテンプレートではない。
2. REFERENCES.md にある動画のうち最低2本を、可能な方法で実際に映像として確認する。タイトルや説明文だけでは不可。映像を見られない場合は見たふりをせず、利用可能な方法（ユーザーに30〜60秒の参考クリップ/数枚の画面キャプチャを依頼する等）を1回で提案する。確認できた場面のタイムスタンプに基づいて、立ち絵の使い方、字幕、画面構成、静止画の切り替え、間を分析する。映像演出の仕組みは参考にするが、構図・素材・テロップ等の丸写しはしない。
3. 同梱の『日本酒担当のおじさん』の元画像を参考にし、正確な透過処理・各ポーズ素材・顔/頭/足の安全領域を検証する。画像の端を切らない。
4. VOICEVOXの自然な日本語ナレーション、字幕、効果のある間、和風歴史挿絵と酒蔵画像などを用いて、40〜60秒の試作を完成させる。テーマは『日本酒からリンゴのような香りがするのはなぜ？』。科学的説明（酵母が生成する香気成分、例：カプロン酸エチルや酢酸イソアミル）を誇張・混同せず出典確認する。
5. レンダリング後、冒頭/中盤/末尾とポーズ変更時など全シーンの代表フレームを抽出して視認確認し、字幕の可読性・人物欠け・音声/字幕同期・不自然な繰り返しを確認。問題があれば修正してから提出する。
6. 成果物：動画MP4（ナレーション入り）、プロジェクト/素材一覧、実際に参照した動画の分析メモ（観察タイムスタンプ付き）、QA結果と未解決事項。完成しなかった場合はできたと偽らず、何が不足したか明記する。

【禁止・予算】
- 外部画像生成API等の新規有料課金や、承諾のない契約/購入はしない。ChatGPTでの画像生成は利用できるので、必要な画像は「シート単位でまとめて依頼する指示書」を作って受け取る方式。参考資料・ライセンス明確な写真等・地図/図解のコード描画も組み合わせる。
- 無音声の動画、頭が切れたキャラ、読みづらい字幕、画面が素人っぽい試作を「完成」として提出しない。
- 今回は8分本編を作らず、40〜60秒の小規模試作に限定する。その完成度が確認できた後、長尺制作基盤へ広げる。
- 不必要な小出し確認を繰り返さず、既知の条件を使って進める。

重要：『良い企画』の提案だけでなく、参照映像に学んだ具体的な画面設計と、まともに再生できる映像の品質を証明してください。
