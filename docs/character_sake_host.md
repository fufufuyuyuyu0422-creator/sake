# 日本酒担当の案内人「香蔵（こうぞう）」設定

台本を書くときは、この設定に合わせておじさんの言葉で書くこと。
**ナレーターは置かない。動画の語りは全部、香蔵がしゃべる。**（ナレーションとキャラのセリフで口調が変わると、聞く人が「今しゃべっているのは誰？」となるため。2026-10-11の試作で確認済み）

## 何者か

- 名前: 香蔵（こうぞう）。通称「香蔵じい」。香りの「香」と、酒蔵の「蔵」
- 年: 60歳前後
- 素性: 若いころから酒蔵で働き、長く杜氏を務めた。引退してからは、日本中・世界中の酒を「かぎ歩く」旅をしている
- 自慢: 鼻。かいだだけで造りや香りの元を言い当てる、利き酒の腕
- 見た目: `assets/host/` の和装のおじさん（髷、徳利と猪口、手ぬぐい、巾着）

## 性格

- 職人肌で、ちょっとぶっきらぼう。でも根は面倒見がよく、聞かれると話が止まらない
- 話の順番は「まず自分がかいだこと・蔵で見てきたこと」→「それを理屈（科学・歴史）で確かめる」。体験から入って、知識で裏付ける
- 自分の鼻に自信があって、少し自慢したがる
- **わからないことは「そこは、わしにもわからん」と正直に言う。** 言いすぎない。これは事実確認のルール（docs/sources.md にないことは断定しない）とそろえてある
- ほろ酔いで機嫌はいいが、人に「飲め」とは言わない

## しゃべり方

- 一人称: わし
- 語尾: 「〜だ」「〜さ」「〜なんだよ」「〜だろう？」「〜ってわけだ」。くだけた口調で通す（です・ます調は使わない）
- 「〜じゃ」「〜のう」のような昔話のおじいさん言葉は使わない（漫画っぽくなりすぎる）
- 相づちや間の言葉: 「ふむ」「ほう」「ほら」「……さて」「いやあ」
- 視聴者への呼びかけは、なるべく「ほら」「かいでごらん」など、名指ししない形で
- 科学の説明も香蔵の言葉で言いかえる。例:「酵母ってのはな、目に見えんほど小さい生きもんだ」
- 事実の言い方は弱めるところは弱める。例:「リンゴみたいな香り、と言われとる」

## 決まり文句（毎回使ってよい）

- 始まり: 「……さて、今日はこいつをかいでみようか」
- 締め: 「一杯の向こうには、いつも誰かの仕事があるのさ」（その回の内容に合わせて少し変えてよい）

## やらないこと

- 飲酒をすすめる（「さあ飲もう」「次の一杯を」など）
- 未成年を連想させる話
- 下品な冗談、特定の地域や人をからかう冗談
- 根拠のない断定

## ポーズと気持ちの対応

| ポーズ | 使う場面 |
|---|---|
| normal | 静かに語る |
| talk | 説明する |
| point | 「ほら、あそこだ」と示す |
| surprise | 意外なものを見つけた |
| think | 考えこむ、問いを投げる |
| tokkuri | 香りをかぐ、酒を手にする（飲む動作には使わない） |
| book | 調べたことを確かめる |
| welcome | 始まり・締めのあいさつ |

## 声

- 第一候補: 青山龍星（低く落ち着いた声）。60歳前後の設定に合わせるため
- 比較用: 玄野武宏（試作で使用。若めに聞こえる可能性がある）
- 本番の前に、同じ数行を両方で合成して聞き比べて決める

## 口調の例（試作の台本を香蔵の語りにしたもの）

- 「……さて、今日はこいつをかいでみようか。ほら、リンゴみたいな香りがするだろう？」
- 「ところがこいつは、米の酒だ。リンゴなんざ、どこにも入っとらん」
- 「じゃあこの香り、どこから来たと思う？」
- 「よし、小さくなって、もろみの中をのぞいてみるか」
- 「おっと……こりゃあ、思ったよりにぎやかだ」
- 「この丸いのが酵母さ。こいつらが、酒をつくりながら香りまでこしらえてるってわけだ」
- 「いやあ、小さいのに、たいした働き者だよ」
- 「一杯の向こうには、いつも誰かの仕事があるのさ。今日の主役は、目に見えんほど小さい連中だったがね」
