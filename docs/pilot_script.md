## 香蔵の語りにするときに決めたこと

- **口調**: 「〜だ」「〜さ」「〜ってわけだ」「〜だろう？」で通した。です・ます調、「〜じゃ」「〜のう」は使っていない
- **決まり文句**: 始まりは設定どおり「……さて、今日はこいつをかいでみようか」。締めは「一杯の向こうには、いつも誰かの仕事があるのさ」に「小さな」を足して、この回の主役（酵母）に合わせた
- **体験から理屈へ**: 01〜06 は香蔵がかいだこと・のぞいたこと、07〜09 は本（book のポーズ）で確かめる流れにした
- **呼びかけ**: 「かいでみようか」「どこから来たと思う？」と、名指しせずに問いかける形にした
- **10のポーズ**: 設定表では think は「考えこむ・問いを投げる」なので、感心の一言には normal（静かに語る）を当てた
- 「わし」「そこは、わしにもわからん」は、尺の都合で今回は入れていない

## 事実の言い方（前の版から変えていない方針）

- **「リンゴみたいな香り、と言われとる」**: 資料の表現（リンゴ様の香り）の範囲。成分そのものがリンゴと同じとは言わない
- **「米の酒だ」**: キャラ設定の口調例には「リンゴなんざ、どこにも入っとらん」があるが、使っていない。法律で加えてよい物品（施行令）の中身を確認できていないので、「果物は入っていない」とは断定しない
- **熊本**: 「華やかな吟醸酒を全国に広めた酵母のひとつ」まで。熊本酵母（協会9号）とリンゴの成分は結びつけない
- **「すべての日本酒が」とは言わない**: 01 は目の前の「こいつ」の話にした。11 で「酵母の種類なんかで変わる」と添えた
- **言わないこと**: 低温発酵で香りが出る、という話（研究機関の資料で確認できていない）
- **飲酒をすすめない**: 「かぐ」話にとどめた。「飲め」「次の一杯を」は言わない
- 前の版にあった「どちらも吟醸香の代表」は、尺の都合で削った（出典の範囲の話なので、戻してもよい）
