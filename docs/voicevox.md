# 音声（VOICEVOX）の作り方

まだ一度も試していない。最初に「A: クラウドで動くか」を確認し、だめなら B に切り替える。

## A. クラウドセッション（Linux）でエンジンを動かす

VOICEVOX エンジンは Linux 版が GitHub のリリースで配布されている（VOICEVOX/voicevox_engine の Releases、CPU版）。

1. Releases から Linux CPU 版をダウンロードして展開する（ファイル名は版ごとに違うので、その時の一覧を見て選ぶ）
2. `./run --host 127.0.0.1 --port 50021` で起動
3. `curl http://127.0.0.1:50021/version` で返事があればOK
4. 話者一覧は `curl http://127.0.0.1:50021/speakers`。**話者IDはコードに決め打ちせず、名前で一覧から引く**

合成の流れ（HTTP API）:
```
POST /audio_query?text=<文>&speaker=<id>   → 読み上げ設定のJSON
POST /synthesis?speaker=<id>  (body=上のJSON) → WAV
```
1行（1字幕）ごとに1ファイルに分けて `assets/voice/<話ID>/<場面ID>.wav` に保存する。
場面ごとの長さは WAV の長さ＋間で決める。

ダウンロードがネットワーク制限で止まった場合は、何度も試さずにユーザーへ伝えて B にする。

## B. ユーザーの Windows PC で音声だけ作る

1. PC に VOICEVOX（アプリ版）を入れて起動する（起動中は同じ HTTP API が `127.0.0.1:50021` で使える）
2. Claude が台本から「行ごとのテキスト一覧（CSV）」を作る → ユーザーがアプリに読み込んで書き出す
   （またはPC側で動くスクリプトを渡して一括生成）
3. できた WAV を `assets/voice/<話ID>/` に入れてコミット
4. 残り（画面・合成・検品）はクラウドセッションで回す

## 利用規約・クレジット

- VOICEVOX 本体の規約に加えて、**キャラクターごとに利用規約がある**。YouTube で使う前に、選んだキャラの規約を必ず読む
- 動画内か概要欄に「VOICEVOX:キャラ名」の形式でクレジットを入れるのが一般的。正確な表記は各キャラの規約に従う
