## 確認済み

### 熊本酵母（協会9号酵母）
- 野白金一が熊本県酒造研究所で醪から酵母を分離する試験を重ね、昭和27年ごろ吟醸用の「熊本酵母」を開発
- 昭和43年、日本醸造協会の要望で「協会9号酵母」として採用され、全国に頒布
- 低温でよく発酵し、華やかな芳香とまろやかな風味。昭和60年代の吟醸酒ブームに貢献
- 野白金一（1876〜1964）。熊本県酒造研究所は明治42年設立、大正11年から「香露」を製造
- 出典: 熊本県「熊本酵母」関連資料（PDF） https://www.pref.kumamoto.jp/uploaded/life/117560_209974_misc.pdf
- 使用箇所: 地図ズームの札「熊本県酒造研究所／吟醸用『熊本酵母』が生まれた場所」、`docs/pilot_script.md` の 12 行（「華やかな香りの吟醸酒を全国に広めた酵母のひとつは、熊本生まれ」）
- 注意: 「協会9号の頒布開始年」は資料によって書き方が違うことがあるので、台本で年を言う場合はこの資料の表現（昭和43年に協会9号として採用）に合わせる

### 吟醸香の代表成分と、酵母がつくること
- カプロン酸エチル＝リンゴ様の香り、酢酸イソアミル＝バナナ様の香り。どちらも吟醸香を代表する成分
- どちらも清酒酵母が発酵の途中でつくる（カプロン酸エチルは脂肪酸合成の経路から、酢酸イソアミルはアミノ酸合成の経路から）
- 酵母の育種（セルレニン耐性などでカプロン酸エチルを多くつくる酵母）で、香りの高い酒を安定して造れるようになった
- 出典:
  - 堤 浩子（月桂冠総合研究所）「清酒酵母の香気生成の研究」『生物工学会誌』89巻12号 p.717（2011）特集「酒類の香気成分研究の新展開」 https://www.sbj.or.jp/wp-content/uploads/file/sbj/8912/8912_tokushu_1.pdf
  - 堤 浩子「清酒酵母の香気生成機構」『におい・かおり環境学会誌』46巻5号 p.346（2015）特集「日本酒のかおり」 https://www.jstage.jst.go.jp/article/jao/46/5/46_346/_article/-char/ja/
  - あいち産業科学技術総合センターニュース 2015年1月号（食品工業技術センター） https://www.aichi-inst.jp/other/up_docs/no154_02.pdf
  - 酒類総合研究所「清酒のにおいとその由来について」（2011初版・2025改訂） https://www.nrib.go.jp/data/pdf/seikoumisan.pdf （題名と抜粋のみ確認）
- 台本での扱い: 「リンゴのような香り**といわれます**」「吟醸香の代表」と、資料の言い方の範囲で言う。「すべての日本酒が」とは言わない。最後に「香りの出かたは酵母の種類などによってさまざま」と添える
- 使用箇所: `docs/pilot_script.md` の 01・06〜09・11 行

### 清酒の原料（法律上の定義）
- 清酒は「米、米こうじ及び水を原料として発酵させて、こしたもの」（酒税法第3条第7号）。ほかに「清酒かすその他政令で定める物品」を加えたものも清酒に含まれる
- 出典: 国税庁の解説資料 https://www.nta.go.jp/taxes/sake/qa/01/01.pdf ほか（抜粋で確認）
- 注意: 「政令で定める物品」の中身（酒税法施行令）は確認できていない。だから「果物は一切入っていない」「果物ゼロ」とは断定しない。台本では「お米のお酒」とだけ言う
- 使用箇所: `docs/pilot_script.md` の 02 行（「お米のお酒」）、問い画面の見出し「米の酒に、リンゴの香り？」
